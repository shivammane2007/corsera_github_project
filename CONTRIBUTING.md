
# Contributing Guidelines

Thank you for your interest in contributing to the Simple Interest Calculator project!

## How to Contribute

**All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.**

You can contribute by improving the Bash script, correcting errors, suggesting new features, or improving the project documentation.

## Reporting Bugs

If you find a bug:

1. Check whether the issue has already been reported.
2. Clearly describe the problem.
3. Include the steps needed to reproduce it.
4. Provide the expected and actual results.

## Suggesting Enhancements

When suggesting an enhancement, explain the proposed change, why it would be useful, and how it could improve the project.

## Submitting Changes

1. Fork the repository.
2. Clone your fork to your local computer.
3. Create a new branch for your changes.
4. Make your changes and test them.
5. Commit your changes with a clear commit message.
6. Push your branch to your GitHub fork.
7. Open a pull request describing your changes.

## Code Guidelines

* Keep the Bash script simple and readable.
* Use meaningful variable names.
* Validate user inputs where appropriate.
* Update the README when functionality changes.
* Test your changes before submitting a pull request.

## Code of Conduct

By participating in this project, you agree to follow the guidelines in `CODE_OF_CONDUCT.md`.

Thank you for helping improve this project!
