
# Simple Interest Calculator

## Project Overview

The Simple Interest Calculator is a simple Bash project that calculates
the simple interest on a principal amount based on an annual interest
rate and a specified time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

- Principal: The initial amount of money.
- Rate: The annual interest rate in percentage.
- Time: The duration in years.

## Technologies Used

- Bash
- Git
- GitHub

## How to Run

Execute the following command in your terminal:

```bash
bash simple-interest.sh
```
